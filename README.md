Overview

Dabir is an open-source project featuring a web interface and automated backend workflows designed to streamline processing tasks.

Features

Web Interface: Clean and responsive frontend hosted on GitHub Pages (index.html).

Automation: GitHub Actions workflows (process.yml, cleanup.yml) for automated background execution.

Python Backend: Robust scripts (process.py, cleanup.py) for data and audio/speech processing (librosa).

Repository Structure

index.html: Frontend user interface.

process.py & cleanup.py: Core processing and cleanup scripts.

requirements.txt & requirements-speakers.txt: Dependencies.

.github/workflows/: Automation pipelines.
